Make every hexagon the same color, all white or all black. Tap a hexagon to flip it and the six around it. Arrow keys move, Enter or Space flips.

How to play

Make every hexagon the same color. All white or all black, either one wins.

Clicking a hexagon flips it and all six hexagons touching it. On the edges there are fewer.

The game is endless. The first levels are solved in a single click, then every three levels need one more click. The board grows slowly too.

Every puzzle is made by scrambling a one-color board with real moves, so it can always be solved, and "solve in" is the true fewest number of clicks.

Points grow with the level, and are higher for fewer moves and faster times.
